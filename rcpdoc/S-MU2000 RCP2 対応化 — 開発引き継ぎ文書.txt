## 3. 実装状況

### 解析・タイムライン
- 固定ヘッダー、44-byte track header、4-byte event の解析基盤。
- FE 終端、コメントデータ抽出、中間表現、複数トラックの tick 順統合。
- 文書レベルの時間展開は対応済みイベントのサブセットのみ。未対応コマンドは拒否する。
- 符号付き track offset、負 tick の 0 クランプ、32-bit 範囲超過の拒否。
- ノート移調、gate/note-off 展開。同一トラック・同一移調後音高の再発音時は既存 note-off tick を更新する。
- F5 key signature、E7 tempo の一部、EB Control Change、EC 標準 Program Change、EE Pitch Bend。
- tick から秒への変換補助処理。

### MIDI 出力準備
- MIDI message encoder が Note On/Off、CC、Program Change、Pitch Bend のバイト列を生成する。
- `map_track_midi_outputs(...)` が raw track header byte から channel/port mapping を生成する。下位 nibble=channel、上位 nibble=port/device、bit 7=dummy/unrouted track。
- disabled track のイベントを除外する encoder overload と regression test がある。
- 最新変更：[27b583a](https://github.com/pikachu364/S-MU2000/commit/27b583a981b1f2f474c5b5cebc05d197c495748e)。

### 未実装・未確認
- RCP2 event を既存 player に直接渡す adapter。
- SMF ファイル serialization（SMF loader はあるが、RCP2→SMF writer はない）。
- 実際の RCP2 楽曲での再生互換性。
- E7 の段階的 tempo curve。
- EC の特殊 MT-32/SysEx 経路。
- 0xFC loop、0x98 など未解決コマンド。
- 全コマンドの RCP2 互換性と参照コンバーターとの実データ比較。
