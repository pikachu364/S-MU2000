# RCP2 ファイルの読み込みについて

更新日：2026-10-30

この文書は、S-MU2000 で RCP2 形式の曲ファイル（通常は `.RCP`）を扱う利用者向けの案内です。RCP2 対応は開発中であり、すべての曲を読み込める段階ではありません。

## 対応状況

S-MU2000 の GUI プレイヤーには、RCP2 ファイルを読み取り、対応しているイベントを再生用データに変換する処理が実装されています。ただし、RCP2 のコマンドすべてを実装しているわけではありません。

- 一部の RCP2 ファイルは、イベント比較や解析の検証対象になっています。
- 選定した4サンプルでは、参照コンバーターとのイベント比較で合計94,554イベントが一致しました。
- この比較結果は、その4サンプルについてイベント列を比較した結果です。すべての RCP2 ファイルの読み込み・再生や、実機との音の一致を保証するものではありません。
- 未対応のコマンドが含まれるファイルは、読み込みに失敗することがあります。対応していない部分を省略して、不完全な状態のまま再生することを避けるためです。
- RCP2 対応の確認は継続中です。現時点では、すべての曲に対する互換性を保証できません。

## ファイルを読み込む

RCP2 の読み込みは GUI プレイヤーから行います。SMF 専用の `render` コマンドとは別の経路です。

1. S-MU2000 の `gui` を起動します。
2. MIDI プレイヤーの窓を開きます（ウィンドウ上部の「プレイヤー」）。
3. 曲ファイルをウィンドウへドラッグ＆ドロップするか、プレイヤーの曲一覧へ追加します。
4. 読み込みに成功した曲を選んで再生します。

ファイル選択画面で拡張子による絞り込みが表示されない場合は、「すべてのファイル」を選んでください。

> **注意：** RCP2 ファイルの読み込み処理は実装されていますが、現在の対応コマンドには制限があります。読み込みに失敗した場合は、ファイルが壊れているとは限りません。未対応コマンドや、まだ対応していない形式上の条件が原因の可能性があります。

## `render` コマンドについて

`render` コマンドが直接読み込めるのは、Standard MIDI File（SMF）の形式0・形式1です。RCP2 ファイルを `render` に直接渡すことはできません。RCP2 の再生確認には GUI プレイヤーを使用してください。

## 読み込みに失敗したとき

- ファイルを開けることを確認し、別のファイルでも同じ問題が起きるかを確認してください。
- エラー表示があれば、文面をそのまま控えてください。
- 使用した S-MU2000 のコミットまたはバージョン、OS、ファイル名、エラー表示を添えて報告してください。
- 曲データの権利に注意し、許可なく実曲ファイルを公開リポジトリや不特定多数が見られる場所へアップロードしないでください。
- Yamaha の ROM、ファームウェア、実機から取り出したデータは、報告に添付したり公開したりしないでください。

## 今後について

対応コマンドと制限事項は、検証結果に応じて更新されます。RCP2 の完全対応を意味するものではなく、読み込めるファイルや動作は今後の開発で変わる可能性があります。
